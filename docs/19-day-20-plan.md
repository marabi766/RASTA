## ۱۹٫۳ یکپارچه‌سازی‌های کلیدی این فاز

این‌ها جایی هستند که سرویس‌ها واقعاً به هم می‌رسند و بیشترین ریسک را دارند:

| یکپارچه‌سازی                              | مسیر                                                                     |
| ----------------------------------------- | ------------------------------------------------------------------------ |
| **تجمیع تقاضا → خرید**                    | `DemandRequest` × N → `DemandAggregation` → `RFQ` → `Quotation` → `PO`   |
| **رزرو موجودی در Saga سفارش**             | `ORDER_CREATED` → `reserveStock` → در شکست: `releaseStock` + `releaseHold` |
| **امتیاز عملکرد از چند منبع**             | `REVIEW_SUBMITTED` + `ORDER_COMPLETED` + `REPAIR_COMPLETED` + `CONTRACT_COMPLETED` → `PerformanceScore` |
| **صورت‌وضعیت → پرداخت**                   | `STATEMENT_APPROVED` → `economic` → کارمزد → تسویه → `SETTLEMENT_COMPLETED` |
| **تحلیل ناوگان داخلی/برون‌سپاری**         | `construction` ← REST → `fleet` + `maintenance` (هزینه واقعی)             |
| **Index جست‌وجو از رویداد**               | همه رویدادهای دامنه → OpenSearch؛ **هرگز خواندن مستقیم پایگاه داده دیگر** |
| **سه شاخص اقتصادی**                       | رویدادهای `procurement` + `maintenance` + `economic` → `analytics`        |
