# ADR-018: Monorepo با pnpm workspaces + Turborepo

- **وضعیت:** Accepted
- **تاریخ:** 2026-08-26

## Context

۱۷ سرویس، ۲ Frontend و ۶ بسته مشترک. قراردادهای رویداد و API باید میان همه همگام بمانند.
تیم کوچک است و سربار مدیریت ۲۵ Repository جداگانه توجیه ندارد.

## Decision

**Monorepo** با **pnpm workspaces** برای مدیریت وابستگی و **Turborepo** برای گراف وظایف
و Cache.

**مرزهای وابستگی با ابزار تحمیل می‌شوند، نه با توافق شفاهی.**

## Alternatives Considered

| گزینه | مزیت | عیب | چرا رد شد |
| --- | --- | --- | --- |
| Polyrepo (یک Repo به‌ازای سرویس) | استقلال کامل | تغییر قرارداد نیازمند ۱۷ PR هماهنگ؛ نسخه‌گذاری بسته‌های مشترک | برای تیم کوچک ناممکن |
| Nx | امکانات بیشتر، Generator | پیچیدگی و Lock-in بیشتر | Turborepo برای این اندازه کافی است |
| Lerna | سابقه طولانی | نگهداری کندتر؛ Cache ضعیف‌تر | Turborepo جایگزین بهتری است |
| npm یا yarn workspaces | رایج‌تر | نصب کندتر؛ Hoisting سست‌تر | pnpm سخت‌گیرانه‌تر است و وابستگی پنهان را می‌گیرد |

## Consequences

**مثبت**

- یک نسخه از `@rasta/contracts` برای همه؛ تغییر شکننده در زمان Build دیده می‌شود
- تغییر عرضی (افزودن یک Header به همه سرویس‌ها) در یک PR
- Build افزایشی با Cache — فقط آنچه تغییر کرده دوباره ساخته می‌شود
- pnpm با Symlink سخت‌گیرانه، وابستگی اعلام‌نشده را می‌گیرد

**منفی**

- **وسوسه import میان‌سرویسی** — بزرگ‌ترین ریسک این تصمیم
- Checkout بزرگ‌تر
- CI باید هوشمند باشد وگرنه هر Push همه‌چیز را می‌سازد
- تغییر در `packages/` می‌تواند همه را بشکند

## Compliance

**پاسخ به ریسک اصلی، ابزاری است نه اخلاقی:**

```js
'no-restricted-imports': ['error', {
  patterns: [{
    group: ['**/services/*/src/**'],
    message: 'Cross-service imports are forbidden. Use REST or Kafka events.',
  }],
}]
```

**قواعد گراف وابستگی:**

- سرویس به بسته: مجاز
- بسته به بسته (بدون دور): مجاز
- **سرویس به سرویس: خطای Build**
- **بسته به سرویس: خطای Build**

**قاعده محتوای `packages/`:** فقط Type، Contract، Schema و Utility.
**هیچ Business Logic مشترکی.** اگر پاسخ روشن نیست، **تکرار کد در دو سرویس بهتر از یک
وابستگی مشترک اشتباه است** — تکرار ارزان است؛ جفت‌شدگی نادرست گران.
